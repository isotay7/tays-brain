How to make the key (2 minutes)
  1. Open GitHub's new fine-grained token page and sign in.
  2. Name it something like Brain on my iPhone and pick an expiration. 90 days is fine. When it runs out, the app tells you.
  3. Under Repository access, choose Only select repositories and pick your tays-brain-data repo. Nothing else.
  4. Under Permissions, set Contents to Read-only and Issues to Read and write. GitHub adds Metadata automatically.
  5. Tap Generate token, copy it, and paste it above. GitHub only shows it once.
